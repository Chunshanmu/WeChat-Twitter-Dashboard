# WeChat-Twitter-Dashboard

一个轻量、纯前端运行的**微信朋友圈 / 推特（X）动态排版与预览工具**，专为 9:16 竖图与 1:1 方图混排设计，支持手机与电脑端实时编辑、本地自动保存及高清长图导出。

## 在线使用
> 打开链接即可直接使用，无需登录，所有图片与数据仅保存在本地浏览器中：
> https://chunshanmu.github.io/WeChat-Twitter-Dashboard/

## 核心功能
- **双平台一键切换**：随时在「微信朋友圈」与「推特 / X」主页风格间切换预览，支持手机端 / 宽屏双视图。
- **4 种直角混排方案**：
  - **左 1 右 2 非对称**：竖图 + 两张方图紧凑直角排布，减少裁切。
  - **主图 + 错位小图**：画报风叠层排版，点击小图弹出悬浮滑块，可自由调节位置（X/Y）、大小及白边粗细。
  - **定高胶片横滑**：多图保留原比例横向滑动浏览。
  - **经典朋友圈裁切**：紧凑直角九宫格与人脸上半身聚焦。
- **完整自定义资料与互动**：支持自定义头像、背景封面、昵称、简介、推特 Handle / 加入时间 / 关注数据，以及每条动态的文案、定位、时间、点赞名单、互动数值和评论回复。
- **高清 PNG 导出**：支持导出「完整主页」「仅主页头部」或「单条动态」，自动隐藏编辑按钮，还原真实社交截图。
- **本地自动保存与存档备份**：基于浏览器 IndexedDB 自动保存编辑进度，刷新不丢失；支持一键导出 / 导入 `.json` 项目存档，方便跨设备迁移与继续编辑。

# WeChat-Twitter-Dashboard

一个轻量、纯前端运行的**微信朋友圈 / 推特（X）动态排版与预览工具**，支持手机与电脑端自适应布局、双模式创作（普通图片 / 纯代码）、分组图床图库管理、高清压缩长图导出及自适应 HTML5 组件代码生成。

## 在线使用
> 打开网址即可直接使用，无需登录，所有数据仅保存在本地浏览器中：
> https://chunshanmu.github.io/WeChat-Twitter-Dashboard/

## 核心功能

### 1. 双平台 & 双模式创作
- **微信朋友圈 / 推特（X）一键切换**：还原微信直角紧凑宫格、原生 `··` 互动按钮与点赞评论区，以及推特八瓣蓝标认证、白圈头像与同行无缩进评论。
- **普通图片模式 / 纯代码模式**：
  - **普通图片模式**：支持本地相册上传与图床图库选图，适合日常排版与导出图片。
  - **纯代码模式**：仅从图床图库选图，一键生成无 base64、零外部依赖的自适应 HTML5 完整代码（支持自由导出图片或代码）。
- **多屏自适应**：手机端采用「实时预览 / 编辑」双页签，平板及电脑大屏自动展开为左右双栏同步编辑。

### 2. 四种直角混排方案 & 预览页快捷微调
- **左 1 右 2 非对称**：9:16 竖图 + 两张 1:1 方图紧凑直角排布，减少裁切。
- **主图 + 错位小图**：画报风叠层排版，在预览页**点击小图**即可弹出底部悬浮滑块，实时调节位置（X / Y）、大小与白边粗细，底部留白自动防遮挡。
- **定高胶片横滑**：多图保留原比例横向滑动浏览。
- **经典朋友圈裁切**：直角紧凑九宫格与人脸上半身聚焦。
- **背景图直接微调**：在预览页**点击背景封面**即可弹出悬浮滑块，实时微调背景图上下左右构图，同时适配微信大背景与推特窄横幅。

### 3. 分组图床图库
- 支持**单个添加**与**批量导入**（按行粘贴链接，支持 `名称 | 链接` 格式），自动去重并识别图片比例。
- 支持自定义**分组管理**（新建 / 删除分组、按组筛选、切换图片分组），选头像、背景和配图时可随时弹窗多选调用。

### 4. 自由勾选导出（图片 & 自适应代码）
- **自由多选组合**：支持勾选「包含主页头部」与任意多条动态（如第 1、3、5 条）拼合导出，也可单独导出主页或单条动态。
- **高清智能压缩导出**：固定标准手机端宽度输出 2 倍高清图，支持 **JPG 92% / WebP 92% / 均衡压缩 / 无损 PNG** 四档画质，并实时显示分辨率与文件体积。
- **纯净截长图模式**：无编辑按钮、无滚动条的全屏纯净视图，方便在图床防盗链限制时直接配合手机系统截长图。
- **自适应 HTML5 代码导出**：生成含 `<!DOCTYPE html>`、UTF-8 与 ` ```html ` 标记的完整代码，支持自适应屏幕宽度及父级 `iframe` 去圆角/去边框兼容，可一键复制或下载 `.html`。

### 5. 本地自动保存、存档与历史撤回
- **IndexedDB 本地自动保存**：编辑内容与图库实时保存，刷新或重新打开网页自动恢复进度。
- **项目存档备份**：支持一键导出 / 导入 `.json` 存档文件，方便跨设备迁移与续编。
- **撤回 / 恢复 & 快捷清空**：支持 35 步操作撤回与恢复（电脑端支持 `Ctrl/Cmd + Z`、`Ctrl/Cmd + Y`、`Ctrl/Cmd + Shift + Z`），并提供「清空当前排版」与带二次确认弹窗的「一键清除所有排版」。
